User Management REST API

Project Overview

This project is developed as part of Codomax Internship – Module 05: Java Web & REST API Development.

The project aims to develop a User Management REST API using Java and Spring Boot.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST API
- Postman
- GitHub

Key Features

- Create a new user
- Retrieve all users
- Retrieve user by ID
- Update user details
- Delete a user
- Database connectivity using MySQL

Architecture

The project follows MVC architecture:

- Controller Layer
- Service Layer
- Repository Layer
- Database Layer

Learning Objectives

- Understand HTTP methods and REST APIs.
- Learn Spring Boot application development.
- Implement MVC architecture.
- Connect Java applications with MySQL.
- Perform CRUD operations.
- Test APIs using Postman.
